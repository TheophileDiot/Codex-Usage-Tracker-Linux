# Security reporting

Please report vulnerabilities privately before sharing exploit details in a public issue.
Use **Report a vulnerability** in this repository's Security tab when that option is
available. If it isn't available, open an issue asking for a private contact channel,
without including the vulnerability details.

Include the affected extension and Codex CLI versions, reproduction steps, and the
impact you observed. Use synthetic data. Don't send credentials, `auth.json`, full
configuration files, or conversation content.

This policy covers the extension's local storage, subprocess connection, and native
footer configuration handling. For a vulnerability in Codex itself, use
[OpenAI's security policy](https://github.com/openai/codex/security/policy).

For ordinary display or connection bugs, use the
[bug report template](https://github.com/TheophileDiot/Codex-Usage-Tracker-Linux/issues/new?template=bug_report.md).
